# Reporting security issues

Use GitHub's private vulnerability reporting on this repository for suspected
vulnerabilities, credentials or sensitive findings. Do not post exploit details
or private data in public tasks. If private reporting is unavailable, open a
minimal public request for a private channel without disclosing the finding.

Only test owned local fixtures, disposable environments or systems whose
operator explicitly authorized the specific test. No public attack program,
honeypot authorization or production access is granted by this repository.
